# Sequoia

Open-source embedded Linux platform for **Intel x86**, from [SoCcentric](https://github.com/Soccentric).
MIT licensed.

| Repository | Purpose |
|---|---|
| [Sequoia-OS](https://github.com/soccentric-sequoia/Sequoia-OS) | Yocto/kas image build |
| [meta-sequoia](https://github.com/soccentric-sequoia/meta-sequoia) | Yocto layer for the board |
| [Sequoia-HAL](https://github.com/soccentric-sequoia/Sequoia-HAL) | Hardware abstraction layer (C++17) |
| [Sequoia-Client](https://github.com/soccentric-sequoia/Sequoia-Client) | gRPC client (C++17) |
| [Sequoia-Server](https://github.com/soccentric-sequoia/Sequoia-Server) | Test server (Drogon, C++) |
| [Sequoia-Configuration](https://github.com/soccentric-sequoia/Sequoia-Configuration) | WebConfig on-device configuration |
| [Sequoia-Dashboard](https://github.com/soccentric-sequoia/Sequoia-Dashboard) | HTML5 dashboard |
| [Sequoia-PySDK](https://github.com/soccentric-sequoia/Sequoia-PySDK) | Python SDK |
| [Sequoia-Instrumentation](https://github.com/soccentric-sequoia/Sequoia-Instrumentation) | On-device management and observability |
| [Sequoia-HQ](https://github.com/soccentric-sequoia/Sequoia-HQ) | Fleet management |
| [Sequoia-Hardware](https://github.com/soccentric-sequoia/Sequoia-Hardware) | Hardware documentation |

Contributions go to the `develop` branch. See the shared [contributing guide](https://github.com/soccentric-sequoia/.github/blob/main/CONTRIBUTING.md).
